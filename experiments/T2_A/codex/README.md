## Reglas para futuros añadidos en codex

Identificar fuente/commit, hipótesis y tipo de evidencia. Mantener las nuevas
notas dentro de este directorio. Antes de afirmar un avance de ejecución, enlazar
sus artefactos verificables y distinguirlo del cierre de una visita o trayectoria.
No derivar estados actuales de un texto histórico ni editar tablas oficiales desde
una síntesis. Una instrucción documental no autoriza reanudar el seguimiento.
