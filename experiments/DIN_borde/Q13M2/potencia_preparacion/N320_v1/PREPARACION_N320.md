# Preparación estática del código

Al adaptar el generador de informe,una sustitución de N=200 a una expresión de configuración alcanzó también un título literal y produjo SyntaxError. La compilación AST previa lo detectó antes de publicar código o ejecutar simulaciones. Se corrigió solo el título; no cambió el método. El incidente se conserva aquí. No se ejecutó ni repitió ninguna medición por ese intento de edición.
