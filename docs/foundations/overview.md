# Fundamentos y alcance

RIPG estudia cómo una familia de funcionales sobre un modelo induce relevancias y una geometría entre perspectivas. La investigación separa covariancia de representación, variación geométrica real y posible utilidad predictiva.

Comenzar por el [marco matemático](mathematical-framework.md), el [axioma](admissibility-axiom.md) y el [estado científico](../research-status.md). Las fuentes históricas se conservan; los controles instrumentales no prueban por sí solos utilidad predictiva ni causalidad.
